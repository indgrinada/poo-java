Herança é uma forma de reutilização de software, na qual uma nova classe (subclasse) é criada absorvendo membros de uma classe já existente (superclasse).

O Java permite apenas a "Herança Simples", em que cada subclasse possui apenas uma superclasse direta. Outras linguagens, como C++ por exemplo, podem permitir a "Herança Múltipla".

## Observação

Para garantir que a subclasse herde os atributos da superclasse, eles devem ser definidos como "protected" em vez de "private", como costumamos fazer. 

Outra opção mais segura (para evitar a invalidação de valores acessados diretamente / sem método) é obrigar as sobclasses a acessar os valores da classe via métodos, mantendo os atributos como "private".

## Exemplo

```java
import javax.swing.JOptionPane;

public class EmpregadoComissionado extends Object
{
   protected String nome;                              
   protected String sobrenome;                               
   protected String cpf;                   
   protected double vendasSemanais; 
   protected double porcentagemDeComissao; 
        
   public EmpregadoComissionado(String n, String s,
   String ncpf, double vendas, double porc)                                     
   {                                                          
      nome = n;
      sobrenome = s;
      cpf = ncpf;      
      setVendasSemanais(vendas);       
      setPorcentagemDeComissao(porc);
   }
   
   public void setNome(String n)
   {
      nome = n;
   } 
      
   public String getNome()
   {
      return nome;
   }
      
   public void setSobrenome(String s)
   {
      sobrenome = s;
   }
   
   public String getSobrenome()
   {
      return sobrenome;
   }
   
   public void setCPF(String n)
    {
       cpf = n;
    }
    
    public String getCPF()
    {
       return cpf;
    }
    
    public void setVendasSemanais(double vendas)
    {
       vendasSemanais = (vendas < 0.0)? 0.0 : vendas;
    }
    
    public double getVendasSemanais()
    {
       return vendasSemanais;
    }

    public void setPorcentagemDeComissao(double porc)
    {
       porcentagemDeComissao = 
          (porc > 0.0 && porc < 1.0) ? porc : 0.0;
    }
    
    public double getPorcentagemDeComissao()
    {
       return porcentagemDeComissao;
    }
    
    public double calcula()              
    {                                     
       return vendasSemanais * porcentagemDeComissao;
    }

    public String toString()                                         
    {                                                                
       return "Nome do empregado: " + nome + " " + sobrenome +                
              "\nCPF: " + cpf +            
              "\nVendas Semanais: " + vendasSemanais +                                  
              "\nPorcentagem da comissão: " + porcentagemDeComissao;                       
    }
 } 
 
class EmpregadoComissionadoComSalarioBase4 extends EmpregadoComissionado
{
   private double salarioBase; 
   
   public EmpregadoComissionadoComSalarioBase4 (String n, String s, String ncpf,  
          double vendas, double porc, double salario)                                     
   {                                   
     //chamada explícita ao construtor da superclasse                               
      super(n, s, ncpf, vendas, porc );
      setSalarioBase(salario);
   }
   
   public void setSalarioBase( double salario )
   {
   	  salarioBase = (salario<0.0)?0.0:salario;	
   }
   
   public double getSalarioBase()
   {
   	  return salarioBase; 	
   }   

   public double calcula()              
   {                                     
      return  super.calcula() + getSalarioBase();
   }
   
   public String toString()                                         
   {                                                                
      return super.toString() + "\nSalário base: " + getSalarioBase();
   }
}

//Programa que testa as classes anteriores:
class TestaEmpregadoComissionado4 
{
   public static void main(String args[]) 
   {
      String str;
      EmpregadoComissionadoComSalarioBase4 empregado = new EmpregadoComissionadoComSalarioBase4("José", "da Silva", "22222222222", 5000, 0.04, 300 );      
      
      str = "Nome: " + empregado.getNome()     +
            "\nSobrenome: " + empregado.getSobrenome()+
            "\nCPF: " + empregado.getCPF()      +
            "\nVendas: " + empregado.getVendasSemanais()+
            "\n% de comissão: " + empregado.getPorcentagemDeComissao()+
            "\nSalário base: " + empregado.getSalarioBase();
            
      JOptionPane.showMessageDialog(null, str + "\nSalário final: " + empregado.calcula(), "Dados do empregado", JOptionPane.PLAIN_MESSAGE);
         
      empregado.setSalarioBase(1000);    
         
      JOptionPane.showMessageDialog(null, empregado.toString() + "\nSalário: " + empregado.calcula(), "Dados atualizados do empregado", JOptionPane.INFORMATION_MESSAGE);
      System.exit(0);
   }
}
```

## Biblioteca gráfica Swing

Essa biblioteca serve para **exibir uma janela de diálogo (pop-up)** com uma mensagem simples para o usuário, contendo um botão de confirmação ("OK")

```java
import javax.swing.JOptionPane;

...

JOptionPane.showMessageDialog(null, "<mensagem>", "<título da janela pop-up>", JOptionPane.PLAIN_MESSAGE); 

...

```

O primeiro parâmetro (parrentComponent) define o componente pai da janela. Se passar `null`, a caixa de diálogo aparece centralizada na tela

O quarto parâmetro (messageType) adiciona um tipo de ícone à janela pop-up: 
- JOptionPane.INFORMATION_MESSAGE (Ícone de informação)
- JOptionPane.WARNING_MESSAGE (Ícone de aviso/alerta)
- JOptionPane.ERROR_MESSAGE (Ícone de erro)
- JOptionPane.PLAIN_MESSAGE (Sem ícone)
- JOptionPane.QUESTION_MESSAGE (Ícone de interrogação)

```java
{
   protected String nome;                              
   protected String sobrenome;                               
   protected String cpf;                   
        
   public Pessoa(String n, String s, String ncpf)                                     
   {                                                                  
      nome = n;
      sobrenome = s;
      cpf = ncpf;      
   }
   
   public void setNome(String n)
   {
      nome = n;
   } 
      
   public String getNome()
   {
      return nome;
   }
   
   public void setSobrenome(String s)
   {
      sobrenome = s;
   } 
      
   public String getSobrenome()
   {
      return sobrenome;
   }
   
   public void setCPF(String ncpf)

      cpf = ncpf;

```

2) Elabore a classe específica Aluno que herde as característica da classe Pessoa e que identifique o curso ao qual está matriculado.

```java
}
```
