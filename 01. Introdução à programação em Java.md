## Salvar, Compilar e Executar
Sempre siga essa ordem ao criar projetos.

## Nome de classes
Por padrão, iniciam-se com letra maiúscula e, em casos de nomes compostos, com iniciais maiúsculas. Evite iniciá-los com dígitos e use o "CamelCase". Exemplos de bons nomes são: BoasVindas1; $value, _valor, cod_ent, botao7.

## Tipos de dados primitivos
Em Java, há:  **Char** (16 bits), **Byte** (8 bits), **Short** (16 bits), **Int** (32 bits), **Long** (64 bits), **Float** (32 bits), **Double** (64 bits).

## Entrada de dados
```java
/* Exemplo com a classe para ler dados de entrada */
import java.util.Scanner;

public class ExemploEntrada
{
	public static void main(String args[])
	{
		Scanner input = new Scanner(System.in);
		int num1;
		String frase; // cadeia de caracteres não é um tipo primitivo

		num1 = input.nextInt();
		frase = input.nextLine();
	}
}
```

## Saída de dados
```java
/* Exemplo com o comando para exibir dados na tela */
public class ExemploSaída
{
	public static void main(String args[])
	{
		System.out.print("olá mundo!"); // cursor fica na mesma linha
		System.out.println("olá mundo!"); // cursos vai à próxima linha
		System.out.printf("%s\n%s\n", "olá", "mundo"); // para dados formatados
	}
}
```

## Exercícios
1. Faça um programa que leia um valor em reais e converta em dólar. Exiba o valor.
	```java
	/* Programa que converte valor em Real para Dólar */
	import java.util.Scanner;
	
	public class RealParaDolar
	{
	   public static void main(String args[])
	   {
	      Scanner input = new Scanner(System.in);
	      
	      double valorReal;
	      double valorDolar;
	      
	      System.out.print("Digite o valor em Real R$: ");
	      valorReal = input.nextDouble();
	      
	      valorDolar = valorReal/5.14;
	      
	      System.out.printf("%s %.2f", "Valor em Dolar ($ 1 = R$ 5,14): $", valorDolar);  
	   }
	}
	```

2. Faça um programa que leia o valor em Celsius e converta em Fahrenheit. Calcule e exiba seus valores correspondentes em Fahrenheit. (F = C * 9/5 + 32 )
	```java
	/* Programa que converte de Celsius para Fahrenheit */
	import java.util.Scanner;
	
	public class CelsiusParaFahrenheit
	{
	   public static void main(String args[])
	   {
	      Scanner input = new Scanner(System.in);
	      
	      double valorC; // valor em Celsius
	      double valorF; // valor em Fahrenheit
	      
	      System.out.print("Digite o valor em Celsius: ");
	      valorC = input.nextDouble();
	      
	      valorF = valorC * 9/5.0 + 32;
	      
	      System.out.printf("%s %.2f","Valor em Fahrenheit: ", valorF);  
	   }
	}
	```
